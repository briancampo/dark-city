## 2. Architectural Invariants & Key Decisions
- **Decisions Followed:**
  - **[Decision 0003](../../decisions/0003-multi-tenant-world-instances.md):** Every per-run table (`citizens`, `simulation_events`, `world_events`) carries a `world_id UUID NOT NULL REFERENCES worlds(id)` foreign key constraint. The `worlds` table captures instance lifecycle state (`status`, `sim_clock`, `scenario_id`).
  - **[Decision 0004](../../decisions/0004-observation-and-world-event-capture.md):**
    - `simulation_events.occurred_at` and `world_events.occurred_at` strictly model simulated world-clock time (`sim_clock`) and **never use `DEFAULT now()`**.
    - `world_events.created_at` defaults to `now()` for operational/debugging tracking only.
    - `world_events.origin_citizen_id` is nullable and provenance-only (attribution without making rows M2-eligible).
    - `observable_events` view unions `simulation_events` and `world_events` to provide a single read interface for the Observation module and Narrator.
- **Invariants Maintained:**
  - Zero dead code or unhandled warnings.
  - Public functions and structs have comprehensive doc comments detailing *why* they exist.

## 3. Implementer Self-Identified Risk Areas & Edge Cases
- **Simulated Clock vs Wall Clock:** Any future code inserting into `simulation_events` or `world_events` must explicitly supply the world's `sim_clock` value as `occurred_at`.
- **Database Connection Failure Handling:** `init_pool_with_options` exposes timeout and pool capacity tuning to ensure non-blocking startup and prevent hanging connection attempts when the database is unavailable.
- **Embedded Migrations Path:** Migrations are embedded at compile time from `../../migrations`, ensuring container deployment portability.
