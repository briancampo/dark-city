# Dark Factory Skill: Retrospective Toolkit (`retrospective-toolkit`)

Use this skill to facilitate an end-of-epic retrospective, demonstrate running software to the user, gather cross-role learnings, and generate a durable retrospective brief.

---

## Core Activities

1. **Epic Deliverables Review:** Audit closed issues, acceptance criteria, and PRs for the target Epic.
2. **User Live Demo:** Step-by-step guidance for the Steward to walk the User through running the simulation in the user's environment.
3. **Multi-Role Assessment:** Gather feedback from `.agent/roles/*` (System Architect, Tech Lead, Local Inference Specialist, Character Sculptor, World Designer, QA, Steward).
4. **Retrospective Brief:** Produce `docs/retrospectives/epic-<id>-retro.md` using `docs/templates/epic-retrospective-template.md`.
5. **Continuous Improvement:** Translate retrospective learnings into backlog refinements or tooling updates.
